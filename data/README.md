# Datos

Los archivos `ventas.csv` y `productos.csv` son **sintéticos** y se generan con `python src/generar_datos.py`
(semilla 42). No hace falta descargar nada.

- `ventas.csv`: `fecha`, `producto`, `unidades` (365 días × 12 productos = 4,380 registros).
- `productos.csv`: `producto`, `dias_entrega`, `costo_unitario`, `costo_pedido`, `stock_actual`.
